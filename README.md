# Legal Document Analysis Portal

The Legal Document Analysis Portal is a sophisticated Streamlit application that automates the processing of legal case documents through advanced AI integration and professional output generation.

## Key Features

*   **Automated Document Analysis**: The application uses AI to extract key legal information from intake forms and case documents.
*   **Advanced Media Processing**: The portal integrates with Google Cloud to provide state-of-the-art video and audio analysis.
*   **Professional Output**: The system generates client-ready findings letters and case summaries in multiple formats.
*   **Modern Architecture**: The application is built on a unified Streamlit-Python stack, which ensures high performance, maintainability, and a clean, organized codebase.

## Project Structure

The project is organized into the following directories:

*   **`app.py`**: The main Streamlit application.
*   **`backend_logic/`**: Contains the core business logic, including modules for document processing, AI analysis, and email generation.
*   **`components/`**: Houses the application's UI components.
*   **`utils/`**: Provides utility functions and data models.
*   **`docs/`**: Contains all project documentation.
*   **`memory-bank/`**: The project's knowledge base, with detailed documentation on its architecture, features, and history.

## Getting Started

To run the application locally, first install the required dependencies:

```bash
pip install -r requirements.txt
```

Then, run the Streamlit application:

```bash
streamlit run app.py
```
