# Announcement Email — v2.0.0

**Subject:** Case Analysis Portal Update — Smarter AI, Better Document Management, Improved Letters

---

Hi team,

We've deployed a significant update to the Case Analysis Portal. This release includes a new AI model, better handling of large cases, and a rewritten letter generation pipeline — all aimed at making your case analysis workflow faster and more reliable.

**Key highlights:**

- **GPT-5.4 AI model** — Analysis and letter generation now use GPT-5.4, which is designed to provide stronger legal reasoning and more thorough case assessment. You may notice improved depth in findings emails and gap analysis.

- **Verification Hub** — A new document management interface that groups your case documents by status (Critical, Needs Attention, Ready, Duplicates, Excluded). It's designed to help you quickly identify which documents need OCR, review signatures, and manage duplicates — all from one place.

- **Better large-case handling** — Cases with 50+ documents now use a map-reduce pipeline for gap analysis, designed to produce more consistent and thorough results on complex matters.

- **Rewritten findings emails** — The findings email format has been updated with combined law + application sections, a critic review pass, and a polish step. The output should be more structured and readable.

**What's changed in your workflow:**

1. **Analysis time estimates** are now 2-8 minutes for most cases (up to 10-15 minutes for very large cases with 50+ documents). You'll see real-time progress updates during processing.
2. **Findings emails look different** — the new format uses a combined law + application structure. The content aims to be more precise, but let us know if you prefer the previous format.
3. **Verification Hub is new** — look for it on the case page. The detailed walkthrough (linked below) covers how to use it.
4. **iPhone photos (HEIC)** are now accepted as a document format.

**Getting started:**
- [Detailed walkthrough with screenshots](walkthrough-v2.0.md) — step-by-step guide covering the full workflow
- The **Help** page in the portal has been updated with all current features and a "What's New" section

If you have questions or run into anything unexpected, please reach out.
